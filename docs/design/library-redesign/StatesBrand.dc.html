Три правила: ошибка появляется при уходе из поля, а не на каждом нажатии; текст объясняет последствие, а не повторяет «поле обязательно»; сводка сверху кликабельна и переносит фокус в поле. Предупреждение (охра) не мешает сохранить, ошибка (красный) — мешает.

«Отменить» в сообщении вместо окна «вы уверены?»: одно нажатие вместо двух, а ошибка исправима. Окно подтверждения остаётся только там, где отменить нельзя — удаление аккаунта и восстановление из копии.
