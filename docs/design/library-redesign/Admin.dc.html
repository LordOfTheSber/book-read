Администрирование одной страницей. Сейчас это два пункта меню («Пользователи» с тремя вкладками и «Узлы») — на них приходится два из одиннадцати мест в шапке, хотя видят их единицы. Здесь всё собрано под один пункт «Администрирование» в меню «Ещё», а сверху — четыре показателя состояния, чтобы понять, всё ли в порядке, не открывая вкладок. Плата: страница становится длинной для того, кто пришёл поменять роль одному человеку. Вариантов здесь намеренно один: это служебный раздел, спорить о его композиции дороже, чем о читательских экранах.
